Aplikasi Generator Kartu Ujian

Jenis Kartu

Kartu Bangku berukuran 19 × 6,6 cm, berisi nomor peserta dan nama dengan huruf besar untuk ditempel atau diletakkan di meja.

1. Data & Foto Peserta

* Nama file foto dalam ZIP harus sesuai NISN siswa.

2. Pengaturan Kop & TTD

3. Watermark (Opsional)

Preview Kartu (1)

Petunjuk Penggunaan

  1. Klik Unduh Template Excel, isi data peserta (No. Peserta, NISN, Nama, TTL, Kelas, Ruang).
  2. Klik Upload File .xlsx dan pilih file yang sudah diisi.
  3. Siapkan foto siswa dengan nama file sesuai NISN (contoh 1234567890.jpg), kumpulkan dalam satu file ZIP, lalu klik Upload Foto (.zip).
  4. Atur kop, tanggal, kepala sekolah, dan TTD pada bagian 2. Logo dapat diganti dengan klik kotak logo.
  5. Cek hasil pada Preview, lalu pilih ukuran kertas (A3 bawaan atau A4), lalu klik Cetak. Kartu disusun otomatis dengan jarak 3 mm dan orientasi kertas yang paling banyak memuat kartu. Pada dialog cetak, atur skala 100% (bukan "Fit to page") dan matikan header/footer browser.
