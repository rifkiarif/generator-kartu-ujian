Petunjuk Penggunaan
  1. Klik Unduh Template Excel, isi data peserta (No. Peserta, NISN, Nama, TTL, Kelas, Ruang).
  2. Klik Upload File .xlsx dan pilih file yang sudah diisi.
  3. Siapkan foto siswa dengan nama file sesuai NISN (contoh 1234567890.jpg), kumpulkan dalam satu file ZIP, lalu klik Upload Foto (.zip).
  4. Atur kop, tanggal, kepala sekolah, dan TTD pada halaman Identitas Sekolah. Logo dapat diganti dengan klik kotak logo.
  5. Pilih jenis kartu (Ujian / Bangku) dan atur watermark jika diperlukan.
  6. Cek hasil pada Preview, pilih ukuran kertas (A3 atau A4), lalu klik Cetak. Kartu disusun otomatis dengan jarak 3 mm. Pada dialog cetak, atur skala 100% (bukan “Fit to page”) dan matikan header/footer browser.
