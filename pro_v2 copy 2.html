Petunjuk Penggunaan
  1. Klik Unduh Template Excel, isi data (No. Peserta, NISN, Nama, TTL, Kelas, Ruang). Atau gunakan Tambah Massal (tempel dari Excel) / Tambah 1.
  2. Upload file .xlsx atau proses data massal, lalu upload foto ZIP (nama file = NISN).
  3. Kelola di tabel daftar peserta: cari, edit, hapus. Data tersimpan otomatis di browser Anda.
  4. Atur identitas sekolah (logo, kop, TTD, stempel) pada halaman Identitas.
  5. Pilih jenis kartu (Ujian / Bangku) dan watermark jika perlu.
  6. Preview, pilih kertas A3/A4, lalu cetak. Skala 100% dan matikan header/footer browser.
  7. Denah Tempat Duduk: pilih ruang, jumlah kolom, mode urut/acak, Generate, lalu cetak denah atau absensi yang mengikuti urutan kursi.
  8. Filter Kelas: di halaman Preview & Cetak, pilih kelas untuk mencetak hanya kartu peserta kelas tersebut.
  9. Berita Acara: isi data pelaksanaan ujian, pilih 1 atau 2 pengawas, lalu cetak berita acara sesuai format resmi.

Petunjuk Penggunaan

  1. Klik Unduh Template Excel, isi data peserta (No. Peserta, NISN, Nama, TTL, Kelas, Ruang) — atau gunakan Tambah Massal / Tambah 1 di daftar peserta.
  2. Klik Upload File .xlsx atau tempel data massal (copy dari Excel), lalu unggah foto ZIP (nama file = NISN).
  3. Kelola data di tabel: cari, edit, hapus per baris. Data tersimpan otomatis di browser.
  4. Atur kop, tanggal, kepala sekolah, TTD & stempel. Logo diganti dengan klik kotak logo.
  5. Pilih jenis kartu & watermark, cek Preview, pilih kertas A3/A4, lalu Cetak (skala 100%, matikan header/footer browser).
